# 🎵 MusicAI World - 유튜브 채널 자동화 시스템

본 저장소는 글로벌 음악 및 비주얼 트렌드를 분석하여 자동으로 콘텐츠를 기획, 생성, 편집하고 유튜브 채널에 예약 업로드하는 100% 무인 자동화 에이전트 **루나(Luna)**의 핵심 시스템입니다.

## 🤖 에이전트 루나 (Luna)
- **역할**: AI 음악 및 비주얼 채널 전담 총괄 프로듀서
- **특징**: 데이터 기반의 트렌드 분석, AI 비주얼 및 오디오 생성, 알고리즘 최적화 예약 업로드.

## 📁 주요 기능 및 폴더 구조
- `src/`: 유튜브 자동화의 각 단계를 처리하는 파이썬 스크립트 엔진
  - `trend_scanner.py`: 구글 트렌드 및 인기 키워드 스캔
  - `video_generator.py`: 이미지 및 오디오 결합 비디오 제작
  - `youtube_publisher.py`: YouTube Data API v3를 활용한 자동 업로드
- `config/`: 환경 설정 및 구글 API 자격증명 관리
